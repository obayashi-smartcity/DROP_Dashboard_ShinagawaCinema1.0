# raw フォルダ（元データ置き場）

Google Drive からダウンロードした みんまちDROP の元データ（例：`json-shinagawa-cinema-2026-20261125.zip`）をこのフォルダに置きます。

- zip のままで大丈夫です。zip が複数あるときは、いちばん新しいものを使います。
- zip を展開した JSON（`mart_ga.json` など）を置いてもかまいません。
- **このフォルダの中身は `.gitignore` の設定で GitHub に上がりません**（この README だけ上がります）。元データにはアカウント名・投稿本文・性別・年代などが入っているためです。
