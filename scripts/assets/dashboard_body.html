GAの流入経路の分け方

  • 映画祭の告知：utm_campaign＝shinagawa_cinema の行を utm_source で分類。オンライン＝official_web・intranet・machiapps・line_app・reactivation、現地・紙＝poster・flyer・screen。
  • 2ページ目で初回訪問が記録された —件は、参照元（DROPのTOP）URLのUTMで経路を補いました。
  • UTMなし：自然検索（Google・Yahoo!・Bing）、Instagram（l.instagram.com）、直接・参照元不明。
  • 参照元サイト：page_referrer のドメインでまとめました。QRコード・メール・社内イントラなどはリンク元が記録されないため「参照元なし」になります。
  • 他イベント由来：culture_snack・toyama_event のUTM、またはUTMなしで富山・大阪などのスポットページに着地した訪問。
  • 要確認：utm値が意味の読めない文字列（fuvab…／efbdgvibgvba など）の訪問。うち6件は11/6 16時台のPCからで、テスト配信の可能性。

DROP

  • 新規登録＝mart_user の inflow_event_id が shinagawa-cinema-2026 の人。投稿者の登録経路は mart_user_allevent の inflow_event_id と登録日で判定。

「品川への愛着」を目的変数にする分析に向けて

  • 登録時アンケート（映画祭はQ1・Q2）には愛着をたずねる設問が見当たりません。応募時アンケートを後から追加して、愛着の設問を使う予定です。
  • GAの user_pseudo_id と DROPの account_id はほぼ結び付かない（今回のGAで account_id 付きの行は3件）ため、個人単位の説明変数は DROP 側の行動（投稿数・時刻・スポット・登録経路など）が中心になります。
